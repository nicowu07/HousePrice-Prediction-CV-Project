## 房价预测为什么有用：新增的应用文献

**Quanzeng You, Ran Pang, Liangliang Cao and Jiebo Luo, “Image-Based Appraisal of Real Estate Properties,” IEEE Transactions on Multimedia, 2017.**

- [作者论文与摘要](https://arxiv.org/abs/1611.09180)、[作者全文](https://arxiv.org/html/1611.09180v2)、[出版DOI](https://doi.org/10.1109/TMM.2017.2710804)。
- 引用键：`you2017appraisal`。内容核对基于作者全文和摘要；作者页同时列出期刊DOI。
- 摘要和引言把房产估价与买卖双方谈判、交易联系起来，并研究照片提供的价格信息。这适合支撑报告第一段的应用动机。
- 可以支撑“估价为价格讨论和交易提供参考”；不能据此声称本项目已提高中介成交率，或已验证平台用单张照片筛查异常挂牌价。
- 该研究还利用地理邻近关系；引用其背景不表示我们的单图系统复现了它的方法或输入设置。

**Zillow, “What is a Zestimate?”（可选）**

- [官方页面](https://www.zillow.com/zestimate/)，查阅日期2026-10-24；引用键：`zillow_zestimate`。
- 官方将自动估价定位为帮助房主、买卖双方了解价值的初步参考，并说明它不能代替专业估价。
- 这是业务动机的实例。它使用房屋属性、记录等多种信息，不能用来证明我们仅凭单图就具备同等用途或效果。

第一段通常引用You等人的论文一次就足够；无需为增加引用数量同时加入Zillow。

## 与建议的段落对应

- 引言：优先用You等人的房产估价论文支持实际动机；DINOv3的模型出处放到Method首次介绍处，避免引言成为模型综述。
- 方法的特征段：首次介绍 DINOv2／DINOv3 时引用原论文；随后写清我们实际使用的 checkpoint、输入尺寸、冻结设置和特征聚合。
- 方法的训练段：介绍 AdamW 时引用其论文；介绍 isotonic 校准时可以引用官方说明。
- 实验设置：交代课程数据来自 SoCal 数据集，但实验只使用课程提供的图像与 CSV。
- 回归器对照：介绍 XGBoost 基线时引用原论文，性能排序引用我们自己的结果表。
- 结果／误差分析：本项目 MSE、局部特征的收益、ordinal 对照和失败案例由本项目实验支持，不能由外部论文代替证据。

## 引用时的边界

1. 原论文为借用的编码器或算法提供来源，不会自动证明它在我们的房价任务上更好。
2. 介绍模型时区分原论文的结论与本项目观察。不同 checkpoint 的比较不能直接写成隔离出了预训练目标的因果效应。
3. 自行实现的 ordinal 辅助任务需要描述实际损失，不要引用一个未实现的具体算法来冒充实现来源。
4. 官方软件文档可以作为实现资料；它与研究论文是不同类型的来源。
5. 正文采用 IEEE 数字编号引用；最终只把选用条目加入正式 `references.bib`，再在实际对应句子中引用。
