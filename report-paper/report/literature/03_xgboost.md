# XGBoost

- 题目：XGBoost: A Scalable Tree Boosting System
- 作者：Tianqi Chen、Carlos Guestrin。
- 年份：2016；发表于 KDD 2016。
- 类型：研究论文。
- [论文与摘要页面](https://arxiv.org/abs/1603.02754)
- [出版 DOI](https://doi.org/10.1145/2939672.2939785)
- 建议引用键：`chen2016xgboost`。

## 中文摘要概述

论文介绍可扩展的树提升系统 XGBoost，包括针对稀疏数据的算法、近似树学习的加权分位数方法，以及缓存访问和数据存储等工程优化。它为监督学习提供一种基于提升树的非线性建模方法。

## 本报告可用的内容

- 在回归器对照实验中，注明 XGBoost 基线的来源。
- 解释选择它作为对照的目的：在相同冻结视觉特征上，比较线性回归、提升树和神经回归头。
- 必须同时报告本项目实际超参数与评估协议，不能只引用论文代替实现说明。

可采用的表达方向：在同一组冻结特征上，我们将 MLP 与 Ridge、XGBoost 回归器进行比较。

## 本项目的证据应单独引用

在 DINOv3 ViT-H+@336 特征上，当前记录的 OOF MSE 约为 MLP 70,818、Ridge 72,624、XGBoost 74,140。该排序来自本项目的 `e11_regressors.csv`，不来自 XGBoost 论文。

## 不宜直接据此声称

- 树模型普遍不适合所有视觉特征。
- XGBoost 的当前结果已经代表充分调参后的性能上限。
- 原论文证明 MLP 在本任务中更好。
