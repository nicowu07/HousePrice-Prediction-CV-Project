# DINOv2

- 题目：DINOv2: Learning Robust Visual Features without Supervision
- 作者：Maxime Oquab 等。
- 年份：2023 年 arXiv 初版；当前链接的 v2 更新于 2024-02-02。
- 类型：研究论文。
- [论文与摘要页面](https://arxiv.org/abs/2304.07193)
- [版本 v2](https://arxiv.org/abs/2304.07193v2)
- 建议引用键：`oquab2024dinov2`，最终年份应与采用的书目版本一致。

## 中文摘要概述

论文研究如何通过自监督预训练获得可迁移的通用视觉特征。作者结合数据筛选、规模化训练与蒸馏，训练较大的视觉模型并获得一系列较小模型，在图像和像素级任务中检验其特征质量。其价值是为下游任务提供能够复用的视觉表示。

## 本报告可用的内容

- 在引言中解释为什么先尝试预训练视觉特征，而不是只依赖有限房价标签从头学习视觉表示。
- 在方法中交代 DINOv2 冻结编码器的来源。冻结状态、CLS 与 patch 均值的拼接、输入分辨率及回归器是我们应另行说明的实际配置。
- 在表征对比部分提供背景，随后用本项目的固定五折结果判断它在本任务的表现。

可采用的表达方向：我们采用 DINOv2 预训练编码器作为冻结视觉特征提取器，并在房价标签上训练回归头。

## 不宜直接据此声称

- 该论文证明 DINOv2 在本房价数据上优于全部 CNN。
- 冻结特征必然优于端到端微调。
- 本项目使用的具体 pooling、切块组合或融合策略就是该论文的方法。

这些任务内比较和实现细节需要我们自己的实验与代码支持。
