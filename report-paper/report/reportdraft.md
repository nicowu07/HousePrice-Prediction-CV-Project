# Evaluating Global and Local Visual Features for House Price Prediction

## Introduction

把房产推向市场的很关键的一步就是制定一个合理的价格，房产中介通常结合房屋特征、市场状况和可比成交信息提出挂牌价建议[1]。一个合理的估价可以给中介公司提供一个良好的谈判起点，也可以帮助房地产平台确定哪些房产需要进一步审查价格。尽管这些潜在用途体现了房价预测的实际应用价值，但是根据单张图片来估价还是有困难的。照片可以包含建筑风格、可见建筑范围及周边环境的信息，但不会直接提供建筑面积、精确位置或室内状况。同时同一房屋的视角、光照以及遮挡情况不同也会影响对于房价的估算。

我们在项目中利用8,000张带价格标签的图像，在冻结的预训练视觉特征上训练轻量回归器，以适应有限的标签和算力条件。在模型训练的过程中我们重点研究整图与局部特征的结合是否可以降低预测误差以及价格顺序辅助监督能否进一步改善预测。最后我们进一步将相关的实验模型进行融合，探究不同的模型一起使用是否会增加预测的准确率。



## Method

我们整体的思路是先将图片转化为数字特征，再学习这些特征与房价之间的关系。我们先将所有的图片缩放到指定的正方形输入尺寸，之后使用了冻结参数的DINOv3[2]的图像模型来提取特征，使用价格标签训练一个小型回归网络。为了检验局部视角能否提供额外的信息，我们分别处理完整图片，以及将原图按2×2网格均分得到的四个互不重叠的局部块。每个图像块分别缩放并提取特征，再将四组特征平均，与整图特征拼接后输入回归网络。之后我们通过对照试验来评估这种整体+局部的组合是否优于只使用整图。

在价格预测部分，我们使用了一个小型的神经网络（MLP）。输入特征先用训练部分的统计量进行标准化；目标价格也先取对数并标准化，使其处于较集中的数值尺度，预测后再还原为价格。另外还研究了一个辅助任务，即让网络同时判断房价是否大于四个价格阈值（这些阈值是根据相应的训练部分的价格分布来确定的，把房屋分成数量大致相等的五个组）。因此网络在学习具体的数值的时候，也在学习价格的高低顺序。训练目标是价格预测误差和顺序判断误差，参数λ控制辅助任务的权重。两个任务共用回归网络，但是最终估价只用价格预测输出。所有的结果都在还原后的原始价格尺度上进行评价。

$$
\mathcal{L}=\mathcal{L}_{\mathrm{price}}+\lambda\mathcal{L}_{\mathrm{order}}.
$$

**表1　训练目标及符号说明 / Training objective and notation**

| 符号 | 含义 | 本项目的计算方式或取值 |
| --- | --- | --- |
| $\mathcal{L}$ | 总训练损失 | 价格预测损失与加权辅助损失之和 |
| $\mathcal{L}_{\mathrm{price}}$ | 价格预测损失 | 标准化后的 log(price) 的平均平方误差 |
| $\mathcal{L}_{\mathrm{order}}$ | 四个价格阈值判断的辅助损失 | 四个二元判断的二元交叉熵，在样本和阈值上取平均 |
| $\lambda$ | 辅助损失的权重 | 组合实验为0.3；仅回归时为0 |

经过上述的价格预测之后，再对它进行校准，用一条校正曲线来调整预测值使其更接近实际价格，再应用于验证样本。 除了调整单个预测器的输出外，我们还研究了不同的预测器之间是否存在互补性，即不同的视觉特征、输入尺寸、局部视角会产生怎样不同的预测误差。为进一步研究不同图像信息的组合效果，我们在DINOv3之外加入冻结的DINOv2[3]特征，并考察不同输入尺寸的整图特征、局部特征，以及图片尺寸和清晰度等图像统计量的组合。每种特征配置分别训练一个MLP价格预测器，具体组成见表3。我们将九个已有的回归预测器结果加权组合起来，然后对组合结果做整体线性校正。将数据分成五份，轮流选取其中一份评价融合效果。每次使用其余四份已经存在的预测价格和真实价格来确定融合权重以及整体校正参数，然后用这些参数对当前留出的一份数据进行应用。具体的回归网络结构、训练参数和后处理设置见表2。



**表2　回归与后处理设置 / Regression and post-processing configuration**

| 设置项 | 本项目采用的设置 |
| --- | --- |
| 网络结构 | 两个隐藏层，宽度分别为512和256；每层使用BatchNorm、GELU和dropout（0.3） |
| 输出 | 仅回归时为1个标量；加入ordinal时额外输出4个阈值判断，最终估价仍只使用标量输出 |
| 优化器 | AdamW；权重衰减0.01 |
| 学习率调度 | OneCycle；最大学习率0.001，前15%的调度步数用于升高学习率 |
| 训练预算 | 每次回归头训练40轮，每批256个样本 |
| 辅助阈值 | 相应训练部分价格的20%、40%、60%和80%分位数 |
| 单预测器校准 | 每个外层训练部分内部再用普通随机五折生成留出预测，以这些预测与训练标签拟合isotonic单调校正曲线；再应用于外层验证预测 |
| 融合与输出范围 | 九个预测器使用非负最小二乘权重，再作线性校正；最终预测限制在195–2,000千美元 |

**表3　九个融合预测器的输入组成 / Inputs to the nine ensemble members**

| 预测器 | 输入的特征组 | 特征组数 |
| --- | --- | ---: |
| P1 | H+@336 + H+@256 + L@336 + D2L@336 + T + M | 6 |
| P2 | H+@336 + L@336 + M | 3 |
| P3 | H+@336 + L@336 + T + M | 4 |
| P4 | H+@224 + H+@336 | 2 |
| P5 | H+@336 | 1 |
| P6 | H+@256 | 1 |
| P7 | L@336 | 1 |
| P8 | T | 1 |
| P9 | D2L@518 | 1 |

*表注：H+、L分别为DINOv3 ViT-H+、ViT-L，D2L为DINOv2 ViT-L；@s表示s×s像素输入。T为L@224提取的2×2局部块特征均值；M为19项图像统计特征（如尺寸、清晰度）。*



## Experiments and Results

为检验不同设计的预测效果，本实验使用控制变量法在共同的评价条件下比较价格预测方法、图像输入、辅助任务和预测组合。将数据集固定成五组的划分，尽量保持各份的价格分布相近。预测结果使用均方误差（MSE）来评判，数值越低越好。在这一共同设置下，测试MLP、Ridge和XGBoost[4]三个价格预测方法的准确度。三者使用相同的DINOv3 ViT-H+、使用336×336像素输入提取的图像特征。表4(a)显示，MLP、Ridge和XGBoost的MSE分别为70,818、72,624和74,140，MLP在所测试的设置中误差最低。因此，后续主要比较均采用MLP，使我们能够在价格预测方法不变的情况下，分别考察图像输入和辅助任务的作用。

**表4(a)　相同冻结特征下的回归器比较 / Regressors with identical frozen features**

| 回归器 | OOF MSE ↓ |
| --- | ---: |
| MLP | **70,818** |
| Ridge | 72,624 |
| XGBoost | 74,140 |

*表注：三者均使用DINOv3 ViT-H+提取的336×336像素整图特征和相同的固定分组五折划分，已检测到的近重复图片保留在同一折。下列结果表均在原始价格尺度上报告OOF MSE，单位为（千美元）²，数值四舍五入至整数。*

固定价格预测方法后，我们接着检查输入完整照片、局部图像或两者组合是否会影响结果。为保持这组视角比较的图像模型一致，整图和局部均使用DINOv3 ViT-L、224*224像素输入提取特征。只用整图与只用局部的MSE几乎相同，分别为76,802和76,800；将两组特征拼接后，MSE降至74,936，相比整图约降低2.4%（表4(b)）。因此，在当前配置中，局部特征的价值主要体现在补充整图信息，而不是单独替代整图。

**表4(b)　相同编码器下的整图与局部视角比较 / Whole-image and local views with the same encoder**

| 输入特征 | OOF MSE ↓ |
| --- | ---: |
| 整图 | 76,802 |
| 2×2局部块特征均值 | 76,800 |
| 整图与局部特征拼接 | **74,936** |

*表注：整图和每个局部块均使用DINOv3 ViT-L、224×224像素输入；回归器均为仅回归的MLP。三行使用相同评估划分，拼接相对整图的MSE降低约2.4%。这些是单种子结果。*

除了测试不同的组合视角，我们还检验了价格高低判断的辅助任务（ordinal）能否优化预测结果。在这组实验中，我们使用误差较低的ViT-H+、336×336像素输入的整图配置，分别考察是否加入ViT-L@224局部特征、是否开启辅助任务（表5）。由结果可知，辅助任务本身只让整图配置的误差略降，在整图与局部组合时反而略升。由于变化较小且方向不一致，不能确定价格顺序的辅助任务可以带来稳定的额外收益。

**表5　局部分支与价格顺序辅助任务的四组对照 / Local features and ordinal supervision**

| 输入配置 | 仅连续回归（λ=0） | 连续回归＋ordinal（λ=0.3） |
| --- | ---: | ---: |
| 全局DINOv3 ViT-H+@336 | 70,818 | 70,722 |
| 全局DINOv3 ViT-H+@336＋局部DINOv3 ViT-L@224 | **70,236** | 70,367 |

*表注：数值为OOF MSE，单位为（千美元）²。局部特征为四个2×2局部块特征的均值。全局和局部分支使用不同的编码器及输入尺寸，因此这里比较的是加入该局部分支的完整配置；同编码器的视角对照见表4(b)。四组均为单种子结果，小幅差异尚未经过完整的多次重复验证。*

最后我们还尝试了一些不同策略的组合（表6），将六组特征合并后输入同一个MLP，MSE为69,175；同一配置使用三次不同随机初始化训练，再对预测取平均，MSE降至68,522。随后，将九个不同配置预测器的价格输出加权组合，MSE达到65,278，较其中最好的单次训练成员低约5.6%（表6）。由于成员选择复用了开发评估结果，且整体流程没有经过完全独立的验证，所以不能确定九个预测器的组合是最佳组合，只是在所有尝试的组合之中MSE最低。

**表6　特征组合、重复训练平均与预测器融合 / Feature combination and prediction averaging**

| 配置 | 组合对象及训练方式 | OOF MSE ↓ |
| --- | --- | ---: |
| 六组特征拼接＋MLP | 表3的P1；一次随机初始化 | 69,175 |
| 同一六组配置，三种子预测平均 | P1分别使用三次不同随机初始化训练，再平均价格预测 | 68,522 |
| 九成员预测融合 | 表3的P1–P9；非负最小二乘权重＋线性校正 | **65,278** |

*表注：MSE单位为（千美元）²。约5.6%的降低以69,175为比较基准。九成员融合使用各成员单种子的预测，不是在三种子平均的基础上直接追加成员；三行也不构成只改变一个因素的完整消融。65,278是本地开发OOF估计，成员选择和整体流程尚未完全独立验证，不是实测Kaggle成绩。*



## Error Analysis and Discussion

虽然在不断的组合中预测误差又被降低，但不意味着这种改善对所有价格段的房屋图片都有效果。在对组合策略的系统的预测结果分析可以发现，高价房对整体MSE的影响较大：真实价格不低于1,000千美元的1,279张图像占样本的16.0%，却贡献55.7%的总平方误差；且有明确的偏差方向：1,500–2,000千美元段的平均“预测减真实”偏差为−532.1千美元，而700–1,000段为+8.6千美元（图1）。

**图1　最终九成员融合系统的误差与校准分析 / Error and calibration diagnostics for the final ensemble.** (a) 按真实价格分段比较样本占比与总平方误差占比；(b) 各真实价格段的平均“预测−真实”偏差，n为该段样本数；(c) 将预测价格从低到高分成十个等样本组，每组800张，比较组内预测均值与真实均值，虚线表示两者相等。价格和偏差单位均为千美元，最后一个价格段包含2,000。三个面板均使用同一份8,000张图像的最终融合OOF预测；分箱均值接近对角线不代表逐张估价准确，也不消除开发评估的局限。

为进一步展示这些MSE，这里展示了最终模型的四个具体案例（图2）。4244.jpg的房屋外立面清晰，预测价格768.98千美元接近真实价格769千美元，可以作为比较准确的参照。2138.jpg被低估1468千美元，可能是其木质外墙结构以及周边缺乏绿化的土地不足以反映其较高的真实价格。5350.jpg被高估850千美元，可能是其高大的拱形窗，暖色灯光以及草坪等外观与高价值房屋联系起来。2409.jpg则在前景中出现了很多树木的遮挡，影响了模型对于建筑价格的判断。

此外，本研究也受到了可用算力和运行时间的限制，这也就是我们主要采用冻结视觉特征的原因，因此如果在未来仍有机会对此实验进行优化完善，我们可以对视觉模型进行微调，测试是否会对价格预测有所帮助。当前结果仍有进一步优化的空间。



## Conclusion

综合上述的对照和误差分析，冻结视觉特征可以使我们在有限的数据集和算力下也能有效地预估房屋的价格（明显低于Kaggle中提供的 baseline 的MSE151384.8）。在所测试的配置中，整图与局部特征的组合优于单独使用任一视角，而价格顺序辅助任务没有显示明确的额外收益。多次训练的预测平均和不同预测器的组合进一步降低了开发误差，但高价房仍容易被低估。
